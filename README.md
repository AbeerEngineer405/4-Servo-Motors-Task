# 4 Servo Motors Task

This project controls four servo motors using an Arduino Uno.

## Components
- Arduino Uno
- 4 Servo Motors
- Breadboard
- Jumper Wires

## Servo Pins
- Servo 1: Pin 3
- Servo 2: Pin 5
- Servo 3: Pin 6
- Servo 4: Pin 9

## Description
The four servo motors move together from 0 to 180 degrees for approximately 2 seconds, then all servos are held at 90 degrees.

## Simulation
The circuit was designed and tested using Tinkercad.
